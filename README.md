Draw It or Lose is a modern, web based reimagining of the classic 1980s televised drawing games.  In order to meet the client's needs, our proposed solution focuses on a centralized game management system that ensures data integrity and competitive fairness. We will implement an architectural pattern to handle unique identifiers for games, teams, and players, preventing naming conflicts and ensuring that only one game instance exists in memory at any given time. The development will prioritize the Singleton Pattern and Unique Identification (UUID) logic. This ensures that the game engine remains stable and prevents phantom sessions or duplicate data that could crash the server as the user base scales. Hardware will remain on hold until the software architecture is finished to ensure the servers can handle the real time rendering demands.
